# 🎮 The Game — Your Studio's Project

This folder is **yours**. Everything about the game you're designing, building,
and launching lives here.

## What goes in here

| File / folder | What it's for | First touched in |
|---------------|---------------|------------------|
| [`GAME.md`](GAME.md) | Your Game Design Document (GDD) — the master plan | Quest 2 & 6 |
| `RESEARCH.md` | Your research notes — competitors, mechanics, tech | Quest 6 |
| `src/` | The actual game code (start from the skeleton) | Quest 7 |
| `assets/` | Art, sound, fonts | Quest 7+ |
| `LAUNCH.md` | Launch plan, marketing copy, the link | Quest 15 |

> You don't have these files yet — you'll create them as you go. The Quests tell
> you exactly when. Start by copying `../starter-code/game-skeleton/` into `src/`
> when Quest 7 says so.

## The golden rule
**Ship ugly, then polish.** Get something playable fast. A rough game that exists
beats a beautiful game that's only in your head. Always.
