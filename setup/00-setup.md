# 🎒 Act 0 — Get Loaded

> Setup • ~30–45 min • Reward: 100 XP + the **Geared Up** achievement

Before you can forge anything, you need your gear. This is the boring-but-
necessary part. Do it once, do it right, and never think about it again.

**Mission:** Get every tool installed, every account made, and your crew assembled
with roles.

---

## 🛠️ Step 1 — Install the gear (~20 min)

Work through **[The Free AI Toolbox](free-ai-tools.md)** and get these. Check each
box as you go:

- [ ] **claude.ai** account ([claude.ai](https://claude.ai))
- [ ] **Google AI Studio** API key ([aistudio.google.com](https://aistudio.google.com) → "Get API key") — paste it somewhere safe & private for now
- [ ] **Claude Desktop** app ([claude.ai/download](https://claude.ai/download))
- [ ] **VS Code** ([code.visualstudio.com](https://code.visualstudio.com)) + Python & Live Server extensions
- [ ] **Python 3.11+** — check with `python3 --version` in a terminal
- [ ] **Git** ([git-scm.com](https://git-scm.com)) — check with `git --version`
- [ ] **GitHub** account ([github.com](https://github.com))

> 🤖 **Co-pilot tip:** Stuck on an install? Paste the exact error into claude.ai
> with: *"I'm on [Mac/Windows], trying to install [thing], got this error: [paste].
> Walk me through fixing it step by step, assume I'm a beginner."* This is your
> first real lesson — **AI is the best tech-support you'll ever have.**

---

## 📁 Step 2 — Get the campaign on your machine (~5 min)

Your crew needs one shared copy of this repo.

1. One person: make sure this repo is on GitHub (it probably already is — ask
   whoever set this up for the link).
2. Everyone: clone it.
   ```bash
   git clone <the-repo-link>
   cd For-the-boys
   ```
3. Open the folder in VS Code (`File → Open Folder`).

> New to Git? Don't panic — **Quest 8** teaches the team workflow properly. For
> now, cloning is enough.

---

## 👥 Step 3 — Assemble the crew (~10 min)

Open **[CREW.md](../CREW.md)** and fill it in *together*:

1. **Name your studio.** Every great game studio has a name. Pick one. (Nintendo
   means "leave luck to heaven." You can do better... or worse. Have fun.)
2. **Pick roles.** Each person owns one, but *everyone learns every skill*. Roles
   are about who *leads* a thing, not who's the only one allowed to touch it.
3. **Set up your XP tracker** (template's in CREW.md).

> Solo? You're a one-person studio — legendary origin story. Just play all the
> roles yourself, and lean on AI as your virtual crew.

---

## 🏆 Achievement Unlocked: Geared Up

- [ ] Every tool installed
- [ ] API key saved somewhere private
- [ ] Repo cloned and open in VS Code
- [ ] Studio named + roles picked in CREW.md

Log **100 XP** in CREW.md. You're loaded. 🔫

---

## ⚠️ Real Talk before you start

- **Keep your API key secret.** Treat it like a password. Don't paste it in
  Discord, don't commit it to GitHub. Quest 11 shows you exactly why — but start
  the habit now.
- **Free tiers have limits.** If a tool says "you've hit your limit," you didn't
  break anything — take a break or swap to a backup tool from the toolbox.
- **You will get errors.** Everyone does. Errors aren't failure, they're the job.
  The skill you're really learning is *how to get unstuck fast* — and AI makes
  that superpower-level easy.
