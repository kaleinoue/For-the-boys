> Your only job: give them access (5 min, below) and keep the momentum up.

## 📦 What this actually is

A 6-part, 16-lesson ("Quest") campaign that teaches them to genuinely *master* AI —
prompting, AI agents, automation, security, the works — by using those skills to
**design, build, and launch a browser game** anyone can play.

- **Self-paced:** they read a lesson, do the hands-on part, log their XP, move on.
- **Gamified:** XP, ranks, boss challenges, RPG "classes" matched to each kid's real
  talent (Zeppelin/athlete, Leo/musician, Jonah/artist, Jyana/the-engine — motivated,
  does best with a clear target).
- **Co-op:** built for the four of them to do *together*.
- **Real payoff:** at the end there's a live game on the internet with their names on
  it. That's the hook that keeps them going.

You do **not** need to know how to code or use AI to run this. They teach themselves;
you provide access, encouragement, and the occasional nudge.

## 🔑 Step 1 — Give them access (do this once, ~5 min)

The whole campaign lives in a private GitHub repo (an online folder for code +
lessons). Right now only you can see it. Pick **one** option:

### Option A — Make it public *(recommended — simplest, and the game launch is free)*
The lessons contain **no private info** — it's educational content and starter code.
Making it public means the boys (and later, players) can just open a link.

1. Go to the repo: **https://github.com/kaleinoue/For-the-boys**
2. **Settings** → scroll to the bottom (**Danger Zone**) → **Change visibility** →
   **Make public** → confirm.
3. Send the boys the link. Done.

> Bonus: the final lesson launches their game on **GitHub Pages**, which is free
> *only* for public repos. Public now = free launch later.

### Option B — Keep it private, add them as collaborators
If you'd rather keep it locked down:

1. Each boy makes a free GitHub account (the first lesson walks them through it).
2. Repo → **Settings** → **Collaborators** → **Add people** → enter each username.
3. They accept the email invite.

*(They'll still need to be collaborators in Option A too if you want them pushing
their own work — but for simply reading and doing the lessons, public is enough,
and the game can launch free on **itch.io** instead of GitHub Pages.)*

> **My recommendation:** Option A. Less friction, free launch, nothing sensitive
> in the repo. If you're unsure, public is the easy, safe call here.

## 💸 The money question (important)

**This is built to cost nothing.** Every tool is free or has a no-credit-card free
tier, and each one is tagged in the lessons:

- 🟢 **FREE** — genuinely free.
- 🟡 **FREE TIER** — free up to a daily limit, **no card required**.
- 🔴 **COSTS MONEY** — deliberately avoided; if ever mentioned, it's flagged optional.

**The one rule to enforce:** they should **never enter a credit card** without
checking with you first. The campaign tells them this repeatedly, but back it up.
If a tool ever demands a card, they should stop and use one of the free backups the
lessons list. (Full breakdown: **[setup/free-ai-tools.md](setup/free-ai-tools.md)**.)

## 🗓️ How to run it (suggested)

There's no fixed schedule, but a rhythm helps it actually get finished:

- **One Quest per sitting** (1–2 hrs). Two a week is a great, sustainable pace —
  that finishes the whole thing in about **2 months**.
- **Do it together.** It's co-op; the social part is half the fun and keeps them
  accountable. Same room beats a group call beats solo.
- **Protect the momentum.** The danger zone is the middle (Acts 3–4). If they stall,
  the fix is almost always "just open the next Quest and do Step 1." Starting is the
  hard part.
- **Celebrate the launch.** When they ship the game in Act 6, make it a thing — play
  it, share it, let them show it off. That memory is the whole point.

## 🆘 If they get stuck (and they will)

Getting stuck *is* the skill being taught — the campaign's real lesson is **how to
get unstuck fast using AI.** Before you try to help with tech you don't know, point
them back at their own toolkit:

1. **"Did you read the actual error?"** The answer is usually in it.
2. **"Did you paste it into the AI with context?"** (OS, what they were doing, the
   full error.) This solves ~80% of problems. The lessons drill this.
3. **"Check the CHEATSHEET."** [CHEATSHEET.md](CHEATSHEET.md) has an "unstick ritual."
4. **"Tag a crewmate."** It's co-op — one stuck kid, four brains. (Jyana will want to
   push straight on — the help *he* needs is a clear next step; give him that and
   he'll drive it through.)

If the *whole crew* is blocked on the same thing for more than a day, that's when to
ask for outside help (a techy friend, or have them post the exact error somewhere).
